# 三币物理概率基准

本报告验证六爻抛币物理引擎的长期总体分布是否与三枚独立公平硬币相容。它验证的是统计分布、币面独立性和落稳能力，不替代不同手机型号上的传感器校准与手感测试。

## 方法

- 引擎版本：`v0.1.0-beta.0`
- 样本：20,000 次完整三币抛掷，60,000 个币面
- 固定种子：`0x6d2b79f5`
- 时间步长：`1 / 60 s`
- 每次持握 36–96 帧，并改变加速度幅度、方向、倾斜、旋转速度与释放参数
- 释放后保留短暂衰减动作，再等待三枚硬币经过重力、回弹、摩擦、盘壁碰撞与币间碰撞后全部落稳
- 最多等待 1,200 帧；未落稳的样本单独计数，不会伪造结果

最终正反只通过 `faceFromFlip()` 读取落稳后的物理翻转角度。测试脚本不会直接随机选择最终币面。

## 理论分布

每枚公平硬币正反概率均为 `1/2`，三枚相互独立：

- 6：三反，`1 / 8 = 12.5%`
- 7：一正两反，`3 / 8 = 37.5%`
- 8：两正一反，`3 / 8 = 37.5%`
- 9：三正，`1 / 8 = 12.5%`

## 结果

| 结果 | 理论值 | 模拟值 | 偏差 | 样本数 |
| --- | ---: | ---: | ---: | ---: |
| 6 | 12.500% | 12.310% | -0.190 个百分点 | 2,462 |
| 7 | 37.500% | 37.590% | +0.090 个百分点 | 7,518 |
| 8 | 37.500% | 37.885% | +0.385 个百分点 | 7,577 |
| 9 | 12.500% | 12.215% | -0.285 个百分点 | 2,443 |
| 单枚正面 | 50.000% | 50.002% | +0.002 个百分点 | 30,001 / 60,000 |

- 卡方拟合检验：`χ² = 2.711`，自由度 `3`，`p = 0.438`
- 最大两两币面相关系数绝对值：`0.0089`
- 未落稳模拟：`0`
- 平均落稳时间：`3.051 s`
- 最长落稳时间：`3.600 s`

在通常的 `α = 0.05` 判断标准下，本次测试未发现模拟分布与三枚公平硬币理论分布之间的显著差异。该结论表示数据与公平模型相容，不表示已经数学证明引擎永远公平。

## 复现

在项目根目录执行：

```bash
npm ci
npm run benchmark:probability
```

也可以改变样本数与种子：

```bash
npm run benchmark:probability -- --samples=20000 --seed=1831565813
```

默认 20,000 样本基准设置了预先声明的守卫条件：存在未落稳样本、卡方 `p < 0.01` 或最大币面相关系数超过 `0.03` 时返回失败状态。

## 限制

- 测试输入覆盖一组宽范围的合成持握与摇动轨迹，不等同于采集所有手机用户的动作分布。
- 概率相符不能单独证明碰撞视觉、触觉反馈或传感器映射的主观真实感。
- iPhone、iPad 和更多 Android 型号仍应分别进行真机传感器测试。
- 真实实体硬币也可能因重量分布、磨损、落点材质和抛掷方法产生轻微偏差；本报告使用的是独立公平硬币理论模型。
